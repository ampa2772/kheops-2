Fonctionnalités

Tout ce dont un cabinet a besoin,
dans une seule application.

Conçu autour du quotidien d'un avocat : dossiers, agenda, facturation, documents — interconnectés et accessibles d'un seul clic.

Installation

4 étapes, 2 minutes.

Le programme d'installation s'occupe de tout. Aucune dépendance externe à installer.

  1. 01

    Cliquez sur le bouton de téléchargement

    Le fichier KHEOPS2-Setup.exe sera enregistré dans votre dossier Téléchargements.

  2. 02

    Ouvrez l'installateur

    Double-cliquez sur le fichier depuis votre navigateur ou depuis l'Explorateur Windows.

  3. 03

    Suivez l'assistant

    Validez les étapes par défaut. L'installation prend généralement moins d'une minute.

    ⚠

    Windows peut afficher un avertissement SmartScreen car l'éditeur n'est pas encore enregistré officiellement. Cliquez sur « Informations complémentaires » puis « Exécuter quand même » pour lancer l'installation.

  4. 04

    Lancez KHEOPS 2

    L'application est accessible depuis le Bureau ou le menu Démarrer. Au premier lancement, vous serez guidé pour créer votre profil.

Configuration requise

Léger. Compatible. Discret.

🗑 Désinstallation

Pour désinstaller KHEOPS 2, ouvrez les Paramètres Windows → Applications, recherchez « KHEOPS 2 » puis cliquez sur Désinstaller. La désinstallation est propre et complète : aucune trace résiduelle ni clé de registre orpheline.
